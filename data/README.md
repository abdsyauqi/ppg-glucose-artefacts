# Data

Raw data are not redistributed here. Download them from the original repositories:

| Dataset | Source | Place in |
|---|---|---|
| MUST | Mendeley Data, doi:10.17632/37pm7jk7jn.3 | `data/MUST/RawData/`, `data/MUST/Labels/` |
| STU-BA | Zenodo, doi:10.5281/zenodo.22206256 (CC0) | `data/STU-BA/wfdb_data/`, plus `qc_channels.csv` and `qc_records.csv` in `data/STU-BA/` |

The extracted feature tables in `features/` are sufficient to reproduce every analysis
without the raw data (steps 2 onwards in `run_all.sh`).
